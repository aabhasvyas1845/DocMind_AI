# DocMind AI

DocMind AI is an AI-powered document learning platform designed to make studying and understanding PDF documents easier.

The platform provides a clean workspace where users can upload documents, view PDFs, interact with an AI assistant, and use study-focused tools from a single interface.

## Features

- PDF document upload
- Built-in PDF viewer
- AI-powered chat interface
- Study tools for document-based learning
- Clean and responsive dashboard
- Sidebar navigation for different tools
- Modern and user-friendly interface

## Tech Stack

- **React.js** – Frontend development
- **JavaScript (JSX)** – Application logic and components
- **CSS** – Styling and responsive layout
- **Vite** – Development and build tool
